Muon：从矩阵白化到谱最速下降

面向已经理解 Shampoo 的读者。用一条连续主线串起 matrix sign、极分解、Newton–Schulz、RMS 尺度、MuonW/MuonClip，以及大模型预训练中的真实证据。

MomentUm Orthogonalized by Newton–Schulz 矩阵参数专用 谱范数几何 预训练证据最强
资料核验至 2026-08-07 · 公式约定：权重 $W\in\mathbb{R}^{m\times n}$，$m$ 为 fan-out，$n$ 为 fan-in

00先建立正确的心理模型

如果只能记住一句话：Muon 对动量矩阵做“矩阵版 sign”，保留奇异向量、把非零奇异值拉到约 1，再按层形状校准尺度。

作用对象
2D hidden weights
Linear/attention/MLP 的稠密矩阵；不是所有参数
核心状态
1× momentum
不像 AdamW 还保存逐元素二阶矩；不像 Shampoo 保存两侧矩阵统计
核心算子

你已有 Shampoo 基础，优先读

  1. §5：关掉 Shampoo 累积后为何恰好得到 $UV^T$。
  2. §3：为何这不是“便宜二阶法”这么简单，而是谱范数几何。
  3. §6：为何不做 shape scaling 会让宽矩阵更新过小。
  4. §9：不同论文的“2×”与“1.1×”为何并不直接矛盾。

先排除三个错误印象

  • 不是约束权重正交：被处理的是更新矩阵，不是 $W$ 本身。
  • 不是标准 Newton–Schulz 精确极分解：实用系数故意容忍奇异值在 1 附近振荡。
  • 不是可无脑替换 AdamW：embedding、LM head、bias、norm gain 通常仍交给 AdamW。

01一分钟看懂 Muon

梯度$G_t=\nabla_W\mathcal L_t$
→
动量$M_t=\beta M_{t-1}+(1-\beta)G_t$
→
正交化$O_t\approx\msign(\widetilde M_t)$
→
缩放更新$W_{t+1}=(1-\eta\lambda)W_t-\eta s(W)O_t$

公开实现通常使用 Nesterov 风格的前瞻动量。按 Keller Jordan 当前代码的记法：

$$M_t\leftarrow \beta M_{t-1}+(1-\beta)G_t,\qquad \widetilde M_t\leftarrow \beta M_t+(1-\beta)G_t,$$ $$O_t\leftarrow \operatorname{NS}_5(\widetilde M_t),\qquad W_{t+1}\leftarrow(1-\eta\lambda)W_t-\eta\,s(m,n)O_t.$$

有些论文用未归一化动量 $M_t=\mu M_{t-1}+G_t$。由于 matrix sign 对正数缩放不变，理想精确算子满足 $\msign(cM)=\msign(M)$，两种约定的整体缩放会被正交化抹掉；有限步 NS 下仍可能有小差异。

名字的含义MomentUm Orthogonalized by Newton–Schulz。最关键的设计选择不是 NS 本身，而是“先积累动量，再对整个动量做矩阵正交化”。

02线性代数核心：matrix sign

2.1 从 SVD 到极分解

对秩为 $r$ 的矩阵 $M\in\mathbb R^{m\times n}$，写 reduced SVD：

$$M=U\Sigma V^T,\qquad U\in\mathbb R^{m\times r},\ \Sigma=\operatorname{diag}(\sigma_1,\ldots,\sigma_r),\ V\in\mathbb R^{n\times r}.$$

Muon 的理想算子是矩阵符号/零次幂（也就是极分解中的半正交因子）：

$$\boxed{\msign(M)=UV^T=(MM^T)^{\dagger/2}M=M(M^TM)^{\dagger/2}}$$

其中 $\dagger$ 表示 Moore–Penrose 伪逆。它把每个非零奇异值 $\sigma_i$ 替换为 1，但保留左右奇异向量。若 $m\le n$ 且满行秩，则 $(UV^T)(UV^T)^T=I_m$；若 $m\ge n$ 且满列秩，则 $(UV^T)^T(UV^T)=I_n$，所以准确说是半正交。

逐元素 sign

$g_i\mapsto\operatorname{sign}(g_i)$

抹平坐标幅值，保留每个坐标的正负。

矩阵 sign

$U\Sigma V^T\mapsto UV^T$

抹平奇异值，保留子空间方向。

几何结果

$\kappa(O)=1$（在非零子空间）

原来被大奇异值压制的“稀有方向”被放大。

2.2 最近半正交矩阵

$UV^T$ 还解决正交 Procrustes 问题：

$$UV^T\in\arg\min_{Q\in\mathcal O_{m,n}}\|Q-M\|_F, \quad \mathcal O_{m,n}=\{Q:QQ^T=I_m\ \text{或}\ Q^TQ=I_n\}.$$

这解释“正交化”一词，但不是最深的优化解释。真正回答“为什么这可能是好更新”的，是下一节的谱范数最速下降。

秩亏时的细节若 $M$ 秩亏，最近半正交补全一般不唯一，而 $UV^T$ 的紧致极因子只作用于非零奇异子空间。有限精度 NS 会如何处理极小奇异值，取决于初始归一化、迭代次数和多项式斜率；不能把“所有奇异值严格变成 1”当成工程事实。

03为什么是谱范数最速下降

普通梯度下降默认参数空间是 Euclidean/Frobenius 几何；Muon 主张：Linear 层是从激活到激活的算子，衡量一次更新“有多大”更自然的方式是它最多能把输入放大多少。

3.1 从功能变化定义矩阵大小

Linear 层 $y=Wx$，更新 $\Delta W$ 引起 $\Delta y=\Delta Wx$。若输入输出都按 RMS 计量：

$$\|x\|_{\RMS}=\frac{\|x\|_2}{\sqrt n},\qquad \|y\|_{\RMS}=\frac{\|y\|_2}{\sqrt m},$$ $$\|\Delta W\|_{\RMS\to\RMS} :=\max_{x\ne0}\frac{\|\Delta Wx\|_{\RMS}}{\|x\|_{\RMS}} =\sqrt{\frac nm}\,\|\Delta W\|_2.$$

这里 $\|\cdot\|_2=\sigma_{\max}$ 是谱范数。因此：

$$\|\Delta y\|_{\RMS}\le \|\Delta W\|_{\RMS\to\RMS}\|x\|_{\RMS}.$$

这个不等式把权重空间变化与层的功能变化连起来，也是 shape-aware 学习率缩放的来源。

3.2 对偶范数一步推导出 $UV^T$

先忽略 RMS 前因子，考虑在谱范数信赖域内让线性化损失下降最多：

$$\min_{\|\Delta W\|_2\le \rho}\langle G,\Delta W\rangle_F.$$

谱范数 $S_\infty$ 的对偶是核范数 $S_1$。von Neumann 迹不等式给出：

$$|\langle G,\Delta W\rangle_F|\le \|G\|_*\|\Delta W\|_2, \qquad \|G\|_*=\sum_i\sigma_i(G).$$

令 $G=U\Sigma V^T$，取 $\Delta W=-\rho UV^T$ 达到等号，因此：

$$\boxed{\Delta W^*=-\rho\,UV^T}.$$

若约束改成 RMS-to-RMS 算子范数不超过 $\eta$，则 $\rho=\eta\sqrt{m/n}$：

$$\Delta W^*=-\eta\sqrt{\frac mn}\,UV^T.$$
最重要的理论结论Muon 的方向不是在估计 Hessian 逆，而是某种预先选定的非欧几里得几何中的一阶最速下降方向。写成 $(GG^T)^{-1/2}G$ 看起来像预条件，但预条件器由当前梯度/动量自身构造，不等于曲率逆。

3.3 “最速下降”说法需要一个限定

若解的是带平方惩罚的模型

$$\min_{\Delta W}\ \langle G,\Delta W\rangle_F+\frac{\lambda}{2}\|\Delta W\|_2^2,$$

完整解的幅值还含对偶范数 $\|G\|_*/\lambda$，即 $-(\|G\|_*/\lambda)UV^T$。实用 Muon 通常把方向设为 matrix sign，再用全局/分组学习率和 shape factor 决定幅值。因此更精确的表述是：Muon 实现谱范数最速下降的 duality-map 方向，并另行参数化步长。

04Newton–Schulz 如何避免 SVD

直接 SVD 每一步都昂贵且不适合低精度 GPU 吞吐。Muon 使用仅含矩阵乘法的奇多项式。先归一化 $X_0=M/(\|M\|_F+\varepsilon)$，必要时转置，使“短边”成为左维度；再迭代：

$$X_{k+1}=aX_k+b(X_kX_k^T)X_k+c(X_kX_k^T)^2X_k.$$

若 $X_k=U\Sigma_kV^T$，则：

$$X_{k+1}=U\phi(\Sigma_k)V^T,\qquad \phi(x)=ax+bx^3+cx^5.$$

即每步不改变奇异向量，只对每个奇异值应用标量多项式。传统可收敛系数可取 $(2,-1.5,0.5)$；Muon 默认取：

$$\boxed{(a,b,c)=(3.4445,-4.7750,2.0315),\qquad K=5.}$$
实用系数不是精确极分解这组系数追求原点附近更大斜率，让很小的奇异值在 5 步内迅速长大，代价是不再全局收敛到 1。官方源码明确说明输出更像 $US'V^T$，$S'_{ii}$ 大致落在 $[0.5,1.5]$，而不是精确 $UV^T$。这是有意识的速度/精度折中，不是 bug。

奇异值经过 $K$ 次多项式后的轨迹

Muon 实用系数传统可收敛系数目标 $y=1$

4.1 计算布局

设转置后 $X\in\mathbb R^{r\times q}$ 且 $r\le q$。先算 $A=XX^T\in\mathbb R^{r\times r}$，再算：

A = X @ X.T
B = b * A + c * (A @ A)
X = a * X + B @ X

每步主要是两个 $r\times r$ 与 $r\times q$ 级别矩阵乘法。原作者给出的单矩阵每步成本为 $4q r^2+2r^3$ FLOPs（按乘加计 2 FLOPs），5 步后仍常被大 batch 的前后向计算淹没。关键优势是 bfloat16 GEMM 对 GPU 友好。

数值检查必须先归一化；转置判断必须与恢复转置成对；不要在 CPU 上期待同样的性能；不要默认增加到 10 步会改善训练，Moonlight 报告中更精确的正交化没有带来更好性能。

05从 Shampoo 精确走到 Muon

这部分是两者最干净的代数桥梁，也是最容易被一句“Muon 是无累积 Shampoo”掩盖细节的地方。

5.1 关掉 Shampoo 的时间累积

矩阵版 Shampoo 更新：

$$L_t=\sum_{s\le t}G_sG_s^T,\qquad R_t=\sum_{s\le t}G_s^TG_s,$$ $$\Delta W_t=-\eta L_t^{-1/4}G_tR_t^{-1/4}.$$

若只保留当前梯度，令 $L=GG^T$、$R=G^TG$。代入 $G=U\Sigma V^T$：

$$\begin{aligned} (GG^T)^{-1/4}G(G^TG)^{-1/4} &=U\Sigma^{-1/2}U^T\ U\Sigma V^T\ V\Sigma^{-1/2}V^T\\ &=UV^T. \end{aligned}$$

所以无累积、无动量的 Shampoo = 精确 matrix sign 梯度更新。Muon 再做两项改变：

  1. 对动量 $M_t$ 而不是原始 $G_t$ 做 matrix sign，降低 mini-batch 噪声并形成时间平滑。
  2. 用有限步 Newton–Schulz 直接近似 $UV^T$，不显式形成两侧逆四次根。

5.2 两者到底差在哪里

06更新尺度：最容易漏掉的关键

6.1 半正交矩阵的 RMS 并不恒定

若 $O=UV^T\in\mathbb R^{m\times n}$ 满秩，$r=\min(m,n)$，则：

$$\|O\|_F^2=r,\qquad \RMS(O)=\sqrt{\frac{\|O\|_F^2}{mn}} =\sqrt{\frac{\min(m,n)}{mn}} =\frac{1}{\sqrt{\max(m,n)}}.$$

所以同一个学习率下，最大维度越大，逐元素 RMS 更新越小。大规模训练中，不同 shape 的 attention、MLP、router、GQA/MLA 矩阵会收到不一致的有效更新。

原始 Muon scaling

$$s_{\text{orig}}(m,n)=\sqrt{\max(1,m/n)}.$$

当前 KellerJordan/Muon 使用这一因子。若 $m\ge n$，它把 RMS 从 $1/\sqrt m$ 调到 $1/\sqrt n$；若 $m<n$ 则不变。它带有 fan-in 基准的 muP 风格。

Moonlight RMS matching

$$s_{\text{match}}(m,n)=0.2\sqrt{\max(m,n)}.$$

这样理论更新 RMS 约为 0.2，以匹配作者观测到的 AdamW 更新 RMS 范围，并可复用其学习率量级。常数 0.2 是经验校准，不是数学常数。

还有从 RMS-to-RMS operator norm 直接推导的 $\sqrt{m/n}$ 因子。三种规则对应不同的“什么应该跨层保持不变”的选择，不应混用学习率后直接比较。

版本敏感看到代码中的 Muon 学习率时，必须同时问：用了哪种 `adjust_lr_fn`？是否乘 0.2？矩阵方向如何定义？PyTorch 原生 API 提供 `original` 与 `match_rms_adamw` 两类调整。脱离 scaling 规则谈学习率没有可比性。

6.2 weight decay 为什么在长训练更重要

Moonlight 报告观察到无 weight decay 的 Muon 在早期很快，但长训练中权重与层输出 RMS 持续增长；加入 decoupled weight decay 后改善 over-training 区域：

$$W_{t+1}=(1-\eta_t\lambda)W_t-\eta_t s(m,n)O_t.$$

这与 AdamW 一样把衰减从梯度变换中解耦。当前公开 Muon 和 PyTorch 实现均支持 weight decay。

07最小实现与正确参数分组

7.1 教学版核心代码

import torch

@torch.no_grad()
def zeropower_ns5(g: torch.Tensor, steps: int = 5):
    assert g.ndim == 2
    a, b, c = 3.4445, -4.7750, 2.0315
    x = g.to(torch.bfloat16)
    transposed = x.shape[0] > x.shape[1]
    if transposed:
        x = x.T
    x = x / (x.norm() + 1e-7)
    for _ in range(steps):
        gram = x @ x.T
        x = a * x + (b * gram + c * (gram @ gram)) @ x
    return x.T if transposed else x

@torch.no_grad()
def muon_direction(grad, momentum, beta=0.95):
    momentum.lerp_(grad, 1 - beta)
    nesterov = grad.lerp(momentum, beta)
    update = zeropower_ns5(nesterov)
    update *= max(1.0, update.shape[0] / update.shape[1]) ** 0.5
    return update

这是解释算法的最小骨架，不含 fused/batched/distributed 优化。生产中优先使用经验证实现，例如 PyTorch 2.9+ 的 `torch.optim.Muon` 或项目官方实现，并确认它采用的 shape scaling。

7.3 PyTorch 原生用法

muon_params, adamw_params = [], []
for name, p in model.named_parameters():
    is_hidden_matrix = p.ndim == 2 and "embed" not in name and "lm_head" not in name
    (muon_params if is_hidden_matrix else adamw_params).append(p)

muon = torch.optim.Muon(
    muon_params,
    lr=1e-3,
    momentum=0.95,
    weight_decay=0.1,
    ns_steps=5,
    adjust_lr_fn="match_rms_adamw",
)
adamw = torch.optim.AdamW(
    adamw_params, lr=1e-3, betas=(0.9, 0.95), weight_decay=0.1
)

# 每步对两个 optimizer 同时 zero_grad / step；scheduler 也要同步管理。
不要照抄超参数示例只展示 API 和分组。`lr=1e-3` 是否合理取决于 scaling、模型参数化、batch、schedule 与目标训练长度。原始实现默认 Muon LR 曾为 0.02，而 RMS-matched 大模型配方可复用约 $10^{-3}$ 的 AdamW 量级；数字差异主要来自单位不同。

08计算、内存与分布式

状态内存

Muon：每个参数一份 momentum。

AdamW：通常一阶矩 + 二阶矩两份状态。

在相同精度策略下，Muon optimizer state 可更省。

单步额外计算

每个矩阵 5 次 NS，每次若短边 $r$、长边 $q$，约 $4qr^2+2r^3$ FLOPs。

但 GEMM 尺寸与硬件利用率决定真实 wall-clock。

通信

正交化需要完整矩阵，不能像逐元素 AdamW 那样随意在矩阵内部切碎后独立算。

DP/TP shard 需要 gather 或设计块近似。

原作者按 Linear 层前后向约 $6mnB$ FLOPs 推出额外比例上界约 $Kr/B$，大 token batch 下可低于 1%。但这只是 FLOP 估计；小 batch、小模型、CPU、频繁 optimizer step 或通信受限时，真实开销会更明显。

Moonlight 的 Distributed Muon 采用 ZeRO-1 风格：optimizer state 在 DP 组分片，先对本地分片更新 momentum，再 gather 成完整矩阵做 NS，只保留本地 update 分片，最后 all-gather 参数。报告估算通信量为 AdamW ZeRO-1 的 $(1,1.25]$ 倍，optimizer 延迟约占端到端 1%–3%，并通过 overlap 隐藏。到 2026 年，PyTorch 原生 Muon 与 DeepSpeed 支持已经降低了接入门槛，但具体并行策略仍需按框架核验。

切块会改变数学对每个 shard 分别做 $\msign$ 一般不等于对完整矩阵做 $\msign$。如果为了通信采用 block-wise Muon，必须把它视作新近似并重新验证收敛、更新谱和质量。

09实验证据：强在哪里，边界在哪里

Muon 的经验支持已从 speedrun 扩展到万亿参数训练，但“更好多少”高度依赖模型规模、batch、训练长度、baseline 调参和计量口径。

Kimi K2 / MuonClip。 1.04T total、32B activated MoE 以 15.5T tokens 预训练；QK-Clip 控制 attention logits，报告全程零 loss spike。这证明可扩展性，但使用的是增强版 MuonClip，不是朴素 Muon。

2025-09 / ICLR 2026

系统独立复核。 10 个优化器、0.1B–1.2B、公平调参后，矩阵方法仍领先，但相对 AdamW 的速度优势从 0.1B 约 1.4× 降到 1.2B 约 1.1×；强调末端评估和独立 tuning。

2026

理论与生态成熟。 非凸收敛、critical batch、inexact polar 等分析快速出现；PyTorch/DeepSpeed 提供正式支持。理论能解释特定假设下的优势，但尚没有一个定理完整解释 Transformer 中的全部收益。

9.1 如何同时理解“2×”和“1.1×”

  • 计量不同：匹配 loss 的训练 FLOPs、token 数、step 数和 wall-clock 不是同一个量。
  • 缩放外推不同：Moonlight 拟合 compute-optimal scaling law；独立基准直接测到 1.2B，并观察优势随规模减小。
  • batch 区域不同：Essential AI 发现优势在超大 batch 更明显；另一项研究也指出小 batch 可能改变优化器排序。
  • 调参协议不同：复用 AdamW 超参便于部署，但不等于对每个优化器都做到独立最优。
  • 训练阶段不同：预训练证据明显强于 SFT；中途 checkpoint 排名可能在 LR decay 后翻转。
稳健结论截至核验日期，最保守而有支持的说法是：Muon 是预训练中最可信的 AdamW 挑战者之一，尤其值得在矩阵参数占比高、batch 大、token 昂贵的训练中做公平 A/B；但收益不是普适常数，也不能从小模型 loss 曲线直接外推。

10边界、风险与常见误区

适合优先尝试

  • 从头预训练 Transformer / ConvNet。
  • 主要计算来自大 hidden matrices。
  • 全局 batch 很大，token/data efficiency 重要。
  • 有能力独立调 LR、WD、schedule 并测最终 checkpoint。
  • 框架能高效做 batched NS 或完整矩阵 gather。

谨慎或先不换

  • 短程 SFT、LoRA、RL 或已有 AdamW pretrained checkpoint。
  • 模型以 embedding/稀疏参数/极小矩阵为主。
  • CPU、小 batch 或 optimizer step 已是瓶颈。
  • 现有分片方式拿不到完整矩阵。
  • 没有预算做公平 baseline 与稳定性监控。
误区 1：Muon 在让权重矩阵保持正交

错。Muon 近似正交化的是动量更新 $M_t$，随后把它加到 $W$ 上。$W_t$ 一般不正交。weight decay 与连续更新会塑造权重谱，但那是动态结果，不是显式 Stiefel manifold 约束。

误区 2：所有方向都更新为相同强度，所以会放大纯噪声

有风险但表述过度。理想 matrix sign 会均衡非零奇异值；Muon 先用 momentum 平滑，有限步 NS 对极小奇异值也未必拉到 1。它仍可能放大低信噪比方向，这正是 momentum、batch size 和后续 variance-adaptive 变体的重要性所在。

误区 3：Muon 就是更便宜的 Shampoo，所以表现必然相同

错。Shampoo 的历史二阶统计带来 variance adaptation；Muon 只对平滑的一阶矩做瞬时谱变换。两者在“无累积极限”才代数相等，真实训练动态不同。

误区 4：NS steps 越多越好

错。实用系数不是以无限步收敛到 1 为目标；Moonlight 报告 10 步更精确但无质量收益。增加步数还会增加计算，并可能让多项式动力学进入不希望的区域。

误区 5：Muon 已证明普遍优于 AdamW

错。已有证据集中在预训练，而且独立基准显示收益随规模和设置变化。对 fine-tuning，Moonlight 在 Qwen2.5-7B 上的 Muon-SFT 没有胜过 Adam-SFT；pretrain/finetune optimizer mismatch 仍是研究问题。

10.1 大规模稳定性：为什么出现 MuonClip

Kimi K2 的中等规模实验观察到朴素 Muon 下最大 attention logit 很快超过 1000。MuonClip 在每个 attention head 监控 $S^h_{\max}$，若超过阈值 $\tau$，令 $\gamma_h=\min(1,\tau/S^h_{\max})$，对 query/key 的非共享分量做配对缩放，使 QK 内积回落。K2 使用 $\tau=100$。

这提示一个重要边界：Muon 提高 token efficiency 与 Muon 单独保证超大规模稳定，不是同一件事。万亿参数成功案例依赖 weight decay、RMS matching、QK-Clip 和完整系统工程。

  1. 第一遍：§1 → §2 → §5，掌握算法与 Shampoo 桥梁。
  2. 第二遍：§3 → §4 → §6，亲手推 dual norm、NS 和 RMS。

  4. 动手：完成实验 A，再在你熟悉的训练代码中做实验 B。
  5. 进阶：读 modular norm/duality、收敛分析和 MuonClip。

完成标准

  • 能从 SVD 推出无累积 Shampoo 等于 $UV^T$。
  • 能用谱范数/核范数对偶推出最速方向。
  • 能解释实用 NS 系数为何“不精确反而更快”。
  • 能推出 $\RMS(UV^T)=1/\sqrt{\max(m,n)}$。
  • 能正确拆分 Muon 与 AdamW 参数组。
  • 能解释不同 speedup 报告为何不能直接横比。

五道自测题

1. $G$ 乘以 100 后，精确 Muon 方向会变吗？有限步 NS 呢？

精确 $\msign(cG)=\msign(G)$（$c>0$）不变。NS 前若用 Frobenius norm 完全归一化，理论上也不变；有限精度、epsilon、溢出/下溢可能造成小差异。

2. 为什么 $UV^T$ 是谱范数单位球上的最陡方向？

谱范数的对偶是核范数，$\langle G,Q\rangle\le\|G\|_*\|Q\|_2$；$Q=UV^T$ 满足 $\|Q\|_2=1$ 并使内积达到 $\sum_i\sigma_i(G)$。

3. Muon 与 Shampoo 最本质的时间维差异是什么？

Shampoo 在 $L_t,R_t$ 中积累梯度二阶统计；Muon 只积累一阶 momentum，然后对当前 momentum 做瞬时谱归一化。

4. 一个 $4096\times16384$ 的满秩 semi-orthogonal update，未缩放 RMS 是多少？

$1/\sqrt{16384}=1/128\approx0.0078125$。若希望 RMS 约 0.2，需要乘 $0.2\sqrt{16384}=25.6$。

5. 为什么 embedding 虽是二维矩阵，仍通常不用 Muon？

Embedding 接收 one-hot/稀疏索引，不是稠密 RMS 激活到稠密 RMS 激活的 Linear 算子；对应自然 operator norm 与 hidden Linear 不同，原作者实验也发现 AdamW 更好。
