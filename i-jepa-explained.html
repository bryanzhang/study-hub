I-JEPA 论文讲解

图像联合嵌入预测架构 · 2026-09-22

Self-Supervised Learning from Images with a Joint-Embedding Predictive Architecture
Assran, Duval, Misra, Bojanowski, Vincent, Rabbat, LeCun, Ballas — Meta AI, CVPR 2023
arXiv:2301.08243 · facebookresearch/ijepa

一句话概括

I-JEPA 用一张图里的一个「上下文块」去预测同一张图里几个「目标块」的表征（而不是像素），由此在完全不用手工数据增强、不用负样本的前提下学到语义特征。ViT-Huge/14 在 16 张 A100 上训练不到 72 小时，ImageNet linear probe 达到 79.3%。

三个值得记住的点：

  • 预测发生在表征空间。消融显示改成像素空间预测，1% ImageNet 从 66.9% 掉到 40.7%——这是全文最关键的一条证据。
  • 掩码策略是成败关键，不是配角。多块掩码 54.2% vs 随机掩码 17.6%（1% ImageNet）。
  • 效率。收敛所需迭代数约为 MAE 的 1/5，整体计算量比 MAE 训练同规模 ViT-H/14 省 10 倍以上。

背景：自监督的两条旧路线各自撞墙

I-JEPA 之前，图像自监督主要有两派，各自有一个结构性缺陷。

路线代表工作怎么做痛点
生成式 / 重建式MAE、BEiT遮住一部分像素，在像素空间把它补回来被迫花容量拟合纹理、噪声这些不可预测也无意义的细节；表征语义度低，linear probe 弱，往往要微调才能用
联合嵌入 / 对比式DINO、iBOT、SimCLR把同一张图的两个增强视图编码后拉近依赖手工设计的增强（crop、色抖、翻转），等于把人的先验写死进了不变性，对图像以外的模态很难迁移

两条路线的共同困境可以这么看：重建式把全部信息都当成预测目标，包括根本预测不了的那部分；对比式则靠人工告诉模型「什么变了不算变」来丢掉信息。

I-JEPA 的答案是第三条路：预测目标本身就是一个可学的、会自动丢掉细节的抽象表征。不用人定义不变性，也不强迫模型处理噪声。

核心思想：在表征空间做预测

JEPA 的定义很短：给定输入 x 和目标 y，不要求 x 重建出 y，而是要求 x 的编码能预测 y 的编码。

minθ,φ   ‖ gφ( fθ(x), z )  −  sg[ f̄θ̄(y) ] ‖22

其中 f 是 context encoder，f̄ 是 target encoder（停梯度 + EMA 更新），g 是 predictor，z 是告诉 predictor「要预测哪个位置」的条件变量（实际上就是目标块的位置编码）。

为什么这个改动如此关键：

  1. 表征空间可以丢信息，像素空间不行。预测一只狗每根毛的颜色是不可能的；但预测「这块是狗的躯干」这个抽象描述是可能的。让目标自己去学习该保留什么，等于把「什么值得预测」从人工设计变成了学习出来的。
  2. 不需要多个视图。x 和 y 来自同一张图的不同区域，不用额外的增强管道，所以也就不依赖图像特有的先验。
  3. 能量视角。把预测误差看作能量：兼容的 (x, y) 能量低，不兼容的高。与对比式模型不同的是，JEPA 允许一个 x 对应多个合理的 y，不硬把它们压成同一个点。

注意区分：JEPA 不是生成模型。它不能从表征重建图像，也不应该拿来当生成器用。它的产出只是一个好的编码器。

架构拆解：三个模块

整个模型只有三个部件，都是 ViT。

模块输入输出参数怎么更新
Context encoder fθ上下文块的 patch（已剔除与目标重叠的部分）每个 patch 的表征梯度下降
Target encoder f̄完整图像的全部 patch每个 patch 的表征，再按目标块位置取出作为监督信号EMA，不回传梯度
Predictor gφcontext 表征 + 带位置编码的 mask token目标块各 patch 的预测表征梯度下降

几个容易读漏的细节：

  • Target encoder 看的是完整图，不是裁剪后的块。先编码整张图，再按位置抽取目标 patch 的表征。这意味着目标表征自带上下文，质量更高——论文明确指出先遮挡再编码会降低性能。
  • Predictor 是窄的，它只是个轻量桥接器，训练完就丢掉，下游只用 context encoder。
  • M 个目标块共享一个 predictor，predictor 被调用 M 次，每次换一组位置编码。mask token 本身是一个共享的可学向量，位置信息全靠加上去的 positional embedding 区分。

多块掩码：真正决定成败的设计

论文反复强调：掩码策略是引导模型学到语义特征的核心设计。两条原则——目标块要够大（才能涵盖物体级的语义），上下文块要够分散且信息量足。

参数取值
目标块数量 M4
目标块面积比例0.15 – 0.2
目标块长宽比0.75 – 1.5
上下文块面积比例0.85 – 1.0，长宽比固定为 1
重叠处理从 context 中剔除与任何 target 重叠的 patch

流程是：先在图上采 4 个目标块（允许互相重叠），再采一个占据大部分画面的上下文块，然后把上下文块里和目标重叠的区域挖空。挖空这一步是必须的，否则任务变成了拷贝。注意挖空后上下文是不连续的碎块，这正是「空间上分散」的来源。

消融结果（ViT-B/16，1% ImageNet top-1）把差距拉得很开：

掩码方式top-1
多块（本文）54.2%
单块20.2%
随机 patch17.6%
栅格化（按行块）15.5%

这个对比值得反复品：同样的网络、同样的损失，只换掩码方式，性能差三倍。目标块太小时，预测任务退化成补纹理，学不到物体级的东西。

训练目标与防坍缩

损失就是平均 L2：

ℒ  =  1⁄M   Σi=1..M   Σj∈Bi   ‖ ŝyj − syj ‖22

Bi 是第 i 个目标块包含的 patch 索引集。没有负样本、没有温度系数、没有聚类头、没有 Sinkhorn。

坍缩风险从哪里来

如果 f 和 f̄ 共享参数并同时优化，模型会直接学成常数输出，损失归零但表征无用。I-JEPA 靠两件事防住：

  1. 非对称结构。target encoder 只由 context encoder 的 EMA 得到，梯度不回传，所以目标不会主动向常数靠拢。论文明确说这一点对用 ViT 训练联合嵌入架构是 essential 的。
  2. predictor 带位置条件。它必须针对不同位置给出不同预测，常数解在任务上就是差解。

这套机制和 BYOL / DINO 同源，但 I-JEPA 多了一个条件预测头，所以不需要靠多视图增强来制造正样本对。

实际训练里还有一些常规配置：AdamW、EMA 动量按计划从 0.996 逐步升到 1.0、target 表征做 LayerNorm、bfloat16。这些不是论文的贡献点，但复现时缺一不可。

Clevr 两项是亮点：I-JEPA 在计数和深度这类低层、空间性的任务上反而超过 DINO 和 iBOT。原因不难理解：对比式方法用增强教模型忽略位置和尺度，而这些信息在空间任务上恰恰有用；I-JEPA 没丢。

训练效率

  • ViT-H/14：16 张 A100，< 72 小时（约 1200 GPU 小时）。
  • 比 iBOT 的 ViT-S/16 快约 2.5×；比 MAE 训练 ViT-H/14 省 10× 以上计算。
  • 单步开销与 MAE 相仿，但收敛所需迭代约为 1/5。

消融：哪些设计真的在起作用

消融项结果结论
预测空间：表征 vs 像素66.9% → 40.7%（1% ImageNet）整篇论文最关键的证据；在表征空间预测不是小技巧，是主线
掩码策略多块 54.2% vs 随机 17.6%目标块要大到含语义，上下文要空间分散
target 编码时机先编码完整图优于先遮挡目标表征带上下文，监督信号质量更高
predictor 宽深窄而不浅的配置最好它只需要做空间推理，不需要再建一套表征

一个值得注意的副产品：论文把 predictor 的输出接上一个冻结的解码器可视化后发现，预测出的表征确实对应了正确的物体部件和姿态，但不包含具体纹理。这是「模型学会了丢掉不可预测细节」的直观证据。

意义、局限与后续

在 LeCun 蓝图里的位置

LeCun 在《A Path Towards Autonomous Machine Intelligence》里主张：智能体需要一个世界模型，它在抽象表征空间里预测世界的演化，而不是预测原始感官信号。I-JEPA 是这套主张的第一个大规模实证：把「预测发生在表征空间」从理念变成了可复现的 SOTA 级结果。

需要说清楚的是，I-JEPA 本身并不是世界模型。它预测的是同一时刻的空间缺失部分，没有时间维度、没有动作。它只是把 JEPA 这个计算框架跑通了。

局限

  • 掩码超参敏感。尺度、数量、长宽比都要调，换数据集未必直接能用。
  • 预测目标是移动的（EMA 在变），训练动力学比重建式难分析，坍缩只是经验上避开的，没有理论保证。
  • linear probe 上强，但细粒度识别（iNat18 47.6%）与强增强方法相比仍有差距。
  • 不能生成，也不提供可解释的概率。

后续演进

工作时间关键延伸

从 I-JEPA 到 V-JEPA 2 的主线很清晰：先证明表征空间预测可行，再加上时间，再加上动作——加完这三样，它就真的是个世界模型了。
