PR-AUC vs ROC-AUC 两种评估曲线的原理、区别，以及在类别不平衡数据下的选择 —— 图文调研

一句话总览

ROC-AUC 衡量模型在全体正例与全体负例之间的排序能力，对类别比例不敏感、结果稳定； PR-AUC 聚焦“预测为正的样本里有多少真的是正”，在正例稀少（如你的 50:1）时更能反映真实价值。

一、先搞清楚 4 个基础量

一切都建立在混淆矩阵（Confusion Matrix）上。设“正例”为我们关心的少数类：

预测为正预测为负
真实为正TP 真正例FN 漏报
真实为负FP 误报TN 真负例

ROC 用的两个指标：

  • TPR（召回率 Recall） = TP / (TP+FN) → 真正例里抓到多少
  • FPR = FP / (FP+TN) → 负例里误伤多少

PR 用的两个指标：

  • Precision 精确率 = TP / (TP+FP) → 报警里多少是真的
  • Recall 召回率 = TP / (TP+FN) → 同 TPR
关键差异的根源： FPR 的分母是 FP+TN（全体负例），当负例有 5 万个时，分母巨大，少量 FP 几乎不影响 FPR； 而 Precision 的分母是 TP+FP（预测为正的样本），FP 的增加会直接、显著拉低 Precision。这就是两条曲线在不平衡数据上表现迥异的本质原因。

二、两条曲线怎么画

把分类阈值从高到低滑动，每个阈值得到一组 (TP,FP,FN,TN)，从而得到一个坐标点，连起来就是曲线，曲线下面积就是 AUC。

ROC 曲线

  • 横轴 FPR，纵轴 TPR
  • 左下 (0,0) → 右上 (1,1)
  • 对角线 = 随机猜测，AUC=0.5
  • 越靠左上越好，AUC=1 完美

PR 曲线

  • 横轴 Recall，纵轴 Precision
  • 越靠右上越好
  • 基准线 = 正例比例（你的数据 ≈ 1000/51000 ≈ 0.0196）
  • 随机模型 PR-AUC ≈ 正例比例，而非 0.5

五、什么时候用哪个？

优先 ROC-AUC

  • 正负样本较均衡
  • 你同等关心正类和负类
  • 需要一个对阈值/比例稳定、便于跨实验比较的指标
  • 关心模型整体“排序能力”本身

优先 PR-AUC

  • 严重不平衡（正例稀少）
  • 你只关心把少数“正例”找准找全
  • 误报代价高（每个 FP 都要人去核实）
  • 欺诈检测、风控、疾病筛查、异常检测、信息检索
针对你的数据（负例 5 万、正例 1 千、50:1）： 应以 PR-AUC 为主要选型/调参指标，ROC-AUC 作为辅助参考。 原因：50000 个负例会把 FPR 的分母撑得极大，即便模型误报几百个，FPR 依然很小、ROC-AUC 依旧亮眼， 但这几百个 FP 会让实际使用中的 Precision 惨不忍睹。PR 曲线能如实暴露这个问题。

六、代码：两者怎么算

from sklearn.metrics import roc_auc_score, average_precision_score
from sklearn.metrics import roc_curve, precision_recall_curve

# y_true: 0/1 标签；y_score: 模型输出的正类概率
roc = roc_auc_score(y_true, y_score)              # ROC-AUC
pr  = average_precision_score(y_true, y_score)    # PR-AUC(平均精度 AP，最常用实现)

# 画曲线用的坐标
fpr, tpr, _   = roc_curve(y_true, y_score)
prec, rec, _  = precision_recall_curve(y_true, y_score)

# 交叉验证里指定指标
from sklearn.model_selection import cross_val_score, StratifiedKFold
cv = StratifiedKFold(5, shuffle=True, random_state=0)
cross_val_score(clf, X, y, cv=cv, scoring='average_precision')  # PR-AUC
cross_val_score(clf, X, y, cv=cv, scoring='roc_auc')            # ROC-AUC

注：PR-AUC 常用 average_precision_score（AP，阶梯式精确计算）， 比用梯形法对 PR 曲线积分更稳、更常见。二者数值相近但不完全相同。

七、一句话结论

ROC-AUC 回答“模型能不能把正例排在负例前面”，稳定但在不平衡时过于乐观； PR-AUC 回答“当模型报警时，你能相信它到什么程度、又能覆盖多少真正例”。 正例越稀少，PR-AUC 越是那个说真话的指标。对你的 50:1 任务，以 PR-AUC 为主。
