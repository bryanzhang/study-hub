Transformers are RNNs
线性注意力：从核方法到 2026 年的混合架构

0一页纸速览

论文的全部内容可以压缩成一行代数恒等式：

$$\underbrace{\left(\phi(Q)\,\phi(K)^{\!\top}\right)V}_{\text{先算 }N\times N\text{ 的注意力矩阵}} \;=\; \underbrace{\phi(Q)\left(\phi(K)^{\!\top}V\right)}_{\text{先算 }C\times M\text{ 的小矩阵}}$$

左边是 $\mathcal{O}(N^2)$，右边是 $\mathcal{O}(N)$。这是矩阵乘法的结合律，不是近似，不是采样，不是稀疏化。唯一的代价是：为了能把 $Q,K$ 分离出来，必须先把 softmax 里那个不可分解的 $\exp(q^\top k)$ 换成一个可分解的核 $\phi(q)^\top\phi(k)$。

然后是第二个观察：把上式加上因果掩码（第 $i$ 个位置只能看到 $j\le i$），求和上界从 $N$ 变成 $i$，于是 $\sum_{j=1}^{i}\phi(K_j)V_j^\top$ 变成一个前缀和。前缀和天然可以增量维护：

$$S_i = S_{i-1} + \phi(K_i)V_i^\top$$

——这就是一个隐状态为矩阵的 RNN。于是标题成立：加了因果掩码的线性 Transformer 就是 一个 RNN。推理时每步 $\mathcal{O}(1)$ 时间、$\mathcal{O}(1)$ 内存，不需要 KV cache。论文实测自回归生成最高快 4000×。

① 它解决了什么

长序列训练的 $N^2$ 显存/算力墙，以及自回归解码时 KV cache 随长度线性增长、每步代价随长度线性增长的问题。

② 它没解决什么

固定大小的状态 $S\in\mathbb{R}^{D\times M}$ 装不下任意长的历史。加法式写入永远不遗忘，注意力被稀释。检索/复制类任务显著弱于 softmax。

③ 它启动了什么

整条"线性 RNN"研究线：加衰减（RetNet/Mamba-2）、加门控（GLA/RWKV）、加 delta 规则（DeltaNet）、加两者（Gated DeltaNet），最终落到 2025–2026 的混合架构。

先说结论，避免误解：这篇论文不是说"softmax Transformer 等价于 RNN"。它说的是"如果你把 softmax 换成可分解核，那么因果 Transformer 就是 RNN"。softmax 本身对应的特征映射是无穷维的，无法精确线性化。后来 Mongaras & Larson (TMLR 2025) 证明：线性注意力恰好是 softmax 注意力泰勒展开的一阶截断——这才是两者表达力差距的代数根源。详见第 13 节。

1问题：二次复杂度与自回归解码

1.1 记号约定

沿用原论文记号。输入序列 $x\in\mathbb{R}^{N\times F}$，共 $N$ 个位置、每个位置 $F$ 维特征。一个 Transformer 层：

$$T_l(x) = f_l\big(A_l(x) + x\big) \tag{1}$$

其中 $f_l$ 是逐位置独立的两层 FFN，$A_l$ 是唯一跨位置的自注意力。三个投影：

$$Q = xW_Q,\quad K = xW_K,\quad V = xW_V$$

形状分别是 $W_Q,W_K\in\mathbb{R}^{F\times D}$，$W_V\in\mathbb{R}^{F\times M}$。所以 $Q,K\in\mathbb{R}^{N\times D}$，$V\in\mathbb{R}^{N\times M}$。标准 softmax 注意力：

$$A_l(x) = V' = \mathrm{softmax}\!\left(\frac{QK^{\!\top}}{\sqrt{D}}\right)V \tag{2}$$
记号提示：后文会频繁用下标表示"取第 $i$ 行并当成列向量"，即 $Q_i\in\mathbb{R}^{D}$。$D$ 是 query/key 维度，$M$ 是 value 维度，$C$ 是特征映射 $\phi$ 的输出维度。多头时这些都是每头的维度。

1.2 两个不同的瓶颈

很多人把 Transformer 的效率问题笼统说成"$N^2$ 复杂度"，但其实是两个性质不同的瓶颈，这篇论文的贡献恰恰在于同时解决了它们：

瓶颈发生在症状2020 年前的方案
训练：$\mathcal{O}(N^2)$ 时间与显存 训练 / prefill $N\times N$ 的注意力矩阵必须物化（反向传播要用），显存随 $N^2$ 爆炸 Sparse Transformer $\mathcal{O}(N\sqrt{N})$；Reformer LSH $\mathcal{O}(N\log N)$；Linformer 低秩投影
推理：每步代价随已生成长度线性增长 自回归解码 生成第 $i$ 个 token 要对前 $i$ 个 key 做注意力；KV cache 显存 $\mathcal{O}(i)$；生成整条序列总代价 $\mathcal{O}(N^2)$ 基本没有。稀疏/LSH 方案改善了训练，但解码依然要存全部 KV

论文引言原话点得很清楚：前述那些高效 Transformer "can be efficiently trained on large sequences, they do not speed-up autoregressive inference"。线性注意力的杀手锏在第二行——它把解码时的状态从"随长度增长的 KV 列表"压缩成一个固定大小的矩阵。

2第一步：注意力其实是核方法

2.1 把 softmax 拆开看

把式 (2) 按行写开。第 $i$ 个输出位置：

$$V_i' = \frac{\sum_{j=1}^{N}\exp\!\left(\frac{Q_i^{\!\top}K_j}{\sqrt{D}}\right)V_j}{\sum_{j=1}^{N}\exp\!\left(\frac{Q_i^{\!\top}K_j}{\sqrt{D}}\right)}$$

把 $\exp(\cdot)$ 抽象成任意相似度函数 $\mathrm{sim}(\cdot,\cdot)$，得到广义注意力：

$$V_i' = \frac{\sum_{j=1}^{N}\mathrm{sim}(Q_i,K_j)\,V_j}{\sum_{j=1}^{N}\mathrm{sim}(Q_i,K_j)} \tag{3}$$

这一步是纯粹的换记号，什么都没损失：取 $\mathrm{sim}(q,k)=\exp(q^\top k/\sqrt{D})$ 就精确还原 softmax 注意力。但它揭示了注意力的本质是 Nadaraya–Watson 核回归（kernel smoother）：输出是 value 的加权平均，权重由相似度归一化而来。这个视角来自 Tsai et al. (2019) Transformer Dissection。

2.2 唯一的约束：非负

式 (3) 要成为一个合法的"注意力"（权重构成概率分布），需要什么条件？

只需要 $\mathrm{sim}(\cdot,\cdot)\ge 0$。 论文原文："the only constraint we need to impose to $\mathrm{sim}(\cdot)$ ... is to be non-negative"。理由很直接：

  • 非负保证分母 $\sum_j \mathrm{sim}$ 不会因正负抵消而接近 0（否则式 (3) 数值爆炸）
  • 非负保证每个权重 $\in[0,1]$ 且求和为 1，输出落在 value 的凸包内

所有取值非负的核函数 $k(x,y):\mathbb{R}^{2\times F}\to\mathbb{R}_+$ 都满足这个条件。

这个"非负"约束是后面很多故事的伏笔。 Performer 早期用三角函数随机特征（sin/cos），它可以取负值，结果就是分母偶尔接近 0、训练炸掉——这正是 Performer 最终改用 positive random features 的直接动机。而 DeltaNet（Schlag et al. 2021）走了另一条路：干脆把分母删掉，改用 GroupNorm 稳定输出。今天几乎所有生产级线性注意力都不带这个 $\sum\phi(K_j)$ 分母了。

2.3 核技巧：从"不可分解"到"可分解"

Mercer 定理告诉我们，一个正定核 $k(x,y)$ 总可以写成某个特征映射的内积：$k(x,y)=\langle\phi(x),\phi(y)\rangle$。把这个代入式 (3)：

$$V_i' = \frac{\sum_{j=1}^{N}\phi(Q_i)^{\!\top}\phi(K_j)\,V_j}{\sum_{j=1}^{N}\phi(Q_i)^{\!\top}\phi(K_j)} \tag{4}$$

看起来只是又换了个写法。但关键区别在于：式 (4) 里 $Q_i$ 和 $K_j$ 被彻底分离到了内积的两侧。而 $\exp(q^\top k)$ 做不到——指数函数不能拆成"只含 q 的部分"乘"只含 k 的部分"（在有限维意义下）。

3第二步：结合律 → $\mathcal{O}(N)$

3.1 三行推导

从式 (4) 出发，注意到分子里的求和 $\sum_j$ 与 $\phi(Q_i)$ 无关，可以提出来：

$$V_i' = \frac{\phi(Q_i)^{\!\top}\sum_{j=1}^{N}\phi(K_j)V_j^{\!\top}}{\phi(Q_i)^{\!\top}\sum_{j=1}^{N}\phi(K_j)} \tag{5}$$

向量化写法就是矩阵乘法结合律：

$$\big(\phi(Q)\,\phi(K)^{\!\top}\big)V \;=\; \phi(Q)\big(\phi(K)^{\!\top}V\big) \tag{6}$$
为什么这是免费午餐？ 因为 $\sum_{j}\phi(K_j)V_j^\top$ 与 $i$ 无关——它对所有 query 都是同一个矩阵。原来的做法是对每个 $i$ 都重新扫一遍全部 $j$（$N\times N$ 次），现在只需扫一遍 $K,V$ 算出这个 $C\times M$ 的矩阵，然后每个 query 做一次 $\mathcal{O}(CM)$ 的读取。把"每个 query 独立聚合"变成了"共享一份聚合结果"。

4特征映射 $\phi$ 怎么选

结合律已经给了我们框架，但 $\phi$ 具体取什么？论文讨论了三种可能：

4.1 指数核：无穷维，不可行

$\exp(q^\top k)$ 对应的 RKHS 特征映射是无穷维的（可以从 $\exp(q^\top k)=\sum_{n}\frac{(q^\top k)^n}{n!}$ 看出，每一阶都对应一组张量积特征）。所以精确线性化 softmax 是不可能的。这条路后来分成两支：

  • 随机特征近似：Performer 的 FAVOR+，用 $m=\Theta(d\log d)$ 个随机投影无偏估计 $\exp$ 核
  • 低阶截断：Based 用 2 阶泰勒 $\phi(q)^\top\phi(k)=1+q^\top k+\frac{(q^\top k)^2}{2}$，代价是特征维度 $C=\mathcal{O}(D^2)$

4.2 多项式核：精确有限维

2 次多项式核有精确的有限维特征映射，维度 $C=\mathcal{O}(D^2)$，于是复杂度 $\mathcal{O}(ND^2M)$。论文指出这在 $N \gt D^2$ 时才划算。Tsai et al. (2019) 已经证明多项式核在质量上可以与 exp/RBF 核持平。

4.3 论文的实际选择：$\mathrm{elu}(x)+1$

$$\phi(x) = \mathrm{elu}(x) + 1 = \begin{cases} x+1, & x \gt 0\\ e^{x}, & x\le 0\end{cases} \tag{7}$$

为什么是 elu 而不是 relu？

$\mathrm{relu}(x)+1$ 在 $x\lt 0$ 处梯度为 0，会导致大片 key/query 维度永久死亡——一旦某维进入负区间就再也收不到梯度。elu 在负区间是 $e^x$，梯度是 $e^x \gt 0$，虽然小但不为零。论文原文："We prefer elu over relu to avoid setting the gradients to 0 when x is negative."

为什么要 +1？

保证 $\phi(x) \gt 0$ 严格为正（elu 的值域是 $(-1,\infty)$，加 1 后是 $(0,\infty)$）。这是 2.2 节非负约束的直接落实：$\phi(q)^\top\phi(k)$ 作为正向量的内积必然为正，分母不会归零。

这个选择的好处是 $C=D$：特征映射逐元素作用，不升维，所以复杂度是干净的 $\mathcal{O}(NDM)$，且实现上只是加一行激活函数。

但这是整篇论文最薄弱的一环，也是后续四年被反复攻击的地方。 Zhang et al. 的 Hedgehog & Porcupine（ICLR 2024）系统诊断了原因：好的注意力权重需要两个性质——
① 低熵 / "尖锐"（spiky）：softmax 会把权重集中到少数几个 key 上；
② 单调性：权重应随 $q^\top k$ 单调增。
而 $1+\mathrm{elu}$、Performer、cosFormer 在他们的诊断表里三个都既不 spiky 也不单调，在同一个从零训练的任务上得分约 17.0，而 softmax 是 100.0。他们的解法是把 $\phi$ 学出来：用一个单层 MLP，以 softmax 注意力权重作为软标签、交叉熵训练 $\phi$，从零训练可恢复 >99% 的 Transformer 质量。
2026 年的实践共识：生产级线性注意力基本不用特征映射了。GLA 论文明说"recent work has found that a linear kernel (i.e., setting $\phi$ to be the identity) without a normalizer works well in practice"。取而代之的是：$q,k$ 上做 L2 归一化 或 short conv + SiLU，输出上做 GroupNorm/RMSNorm，然后靠门控/衰减而不是靠 $\phi$ 来获得表达力。见第 12 节。

5第三步：因果掩码 → 前缀和 → RNN

5.1 因果掩码打破了结合律……表面上

自回归模型要求位置 $i$ 只能看 $j\le i$。式 (3) 变成：

$$V_i' = \frac{\sum_{j=1}^{\color{#f78fb2}{i}}\mathrm{sim}(Q_i,K_j)V_j}{\sum_{j=1}^{\color{#f78fb2}{i}}\mathrm{sim}(Q_i,K_j)} \tag{8}$$

问题来了：求和上界现在依赖 $i$ 了。第 3 节那个"所有 query 共享同一个 $\sum_j\phi(K_j)V_j^\top$"的技巧似乎失效——每个 $i$ 需要的是不同的部分和。

但"依赖 $i$ 的部分和"正是前缀和（prefix sum）。 而前缀和有一个平凡的 $\mathcal{O}(N)$ 增量算法：$P_i = P_{i-1} + a_i$。这就是全部的洞见。

5.2 定义两个状态

线性化式 (8)：

$$V_i' = \frac{\phi(Q_i)^{\!\top}\sum_{j=1}^{i}\phi(K_j)V_j^{\!\top}}{\phi(Q_i)^{\!\top}\sum_{j=1}^{i}\phi(K_j)} \tag{9}$$

引入

$$S_i = \sum_{j=1}^{i}\phi(K_j)V_j^{\!\top} \in \mathbb{R}^{C\times M},\qquad Z_i = \sum_{j=1}^{i}\phi(K_j) \in \mathbb{R}^{C} \tag{10,11}$$

式 (9) 就变成极其简洁的

$$V_i' = \frac{\phi(Q_i)^{\!\top}S_i}{\phi(Q_i)^{\!\top}Z_i} \tag{12}$$

而 $S_i,Z_i$ 都能从 $S_{i-1},Z_{i-1}$ 常数时间更新。

形状检查（很值得动手做一遍）：
$\phi(K_j)\in\mathbb{R}^{C\times 1}$，$V_j^\top\in\mathbb{R}^{1\times M}$，外积 $\phi(K_j)V_j^\top\in\mathbb{R}^{C\times M}$ ✓
$\phi(Q_i)^\top\in\mathbb{R}^{1\times C}$，乘 $S_i\in\mathbb{R}^{C\times M}$ 得 $\mathbb{R}^{1\times M}$ ✓ 正是一个 value 向量
分母 $\phi(Q_i)^\top Z_i\in\mathbb{R}$ 是标量 ✓

5.3 完整的 RNN 方程

把式 (1) 的残差和 FFN 也带上，一个完整的因果线性 Transformer 层就是（论文式 16–20）：

$$\begin{aligned} s_0 &= 0,\\ z_0 &= 0,\\ s_i &= s_{i-1} + \phi(x_iW_K)\,(x_iW_V)^{\!\top},\\ z_i &= z_{i-1} + \phi(x_iW_K),\\ y_i &= f_l\!\left(\frac{\phi(x_iW_Q)^{\!\top}s_i}{\phi(x_iW_Q)^{\!\top}z_i} + x_i\right). \end{aligned}$$

这就是标题的全部依据。给定输入 → 更新内部状态 → 产生输出，逐时间步进行——定义上就是一个 RNN。

一个容易搞混的点：论文特意强调，这里的"递归"是沿时间（序列位置）的，不是像 Universal Transformer 那样沿深度的。每一层各自维护自己的 $(s,z)$，层与层之间仍然是前馈的。$L$ 层模型解码时要维护 $L$ 组状态。

6常数内存的反向传播

第 5 节的递推形式在推理时完美。但训练时如果直接照着写，会踩一个大坑。

朴素实现的问题：如果在 PyTorch 里写一个 for 循环逐步更新 $S_i$，autograd 会把每一个中间状态 $S_1,\dots,S_N$ 都存下来用于反向。每个 $S_i$ 是 $C\times M$，总显存 $\mathcal{O}(NCM)$——比原来只存 $\mathcal{O}(N\max(C,M))$ 大了 $\max(C,M)$ 倍。论文原话："This increases the memory consumption by $\max(D,M)$ times; thus hindering the applicability of causal linear attention to longer sequences or deeper models."

6.1 手推梯度：全部都是累积和

论文的解法是手写反向，观察到三个梯度都可以写成累积和形式，从而不需要存中间状态。设分子 $\bar V_i = \phi(Q_i)^\top\sum_{j\le i}\phi(K_j)V_j^\top$，损失对它的梯度为 $\nabla_{\bar V_i}\mathcal{L}$，则：

$$\begin{aligned} \nabla_{\phi(Q_i)}\mathcal{L} &= \nabla_{\bar V_i}\mathcal{L}\left(\sum_{j=1}^{\color{#7ee0c0}{i}}\phi(K_j)V_j^{\!\top}\right)^{\!\top} \tag{13}\\[4pt] \nabla_{\phi(K_i)}\mathcal{L} &= \left(\sum_{j=\color{#f78fb2}{i}}^{\color{#f78fb2}{N}}\phi(Q_j)\big(\nabla_{\bar V_j}\mathcal{L}\big)^{\!\top}\right)V_i \tag{14}\\[4pt] \nabla_{V_i}\mathcal{L} &= \left(\sum_{j=\color{#f78fb2}{i}}^{\color{#f78fb2}{N}}\phi(Q_j)\big(\nabla_{\bar V_j}\mathcal{L}\big)^{\!\top}\right)^{\!\top}\phi(K_i) \tag{15} \end{aligned}$$

关键结构：式 (13) 是前缀和（$j\le i$），式 (14)(15) 是后缀和（$j\ge i$）。所以反向传播是"正向扫一遍 + 反向扫一遍"，每次只需维护一个 $C\times M$ 的累加器，而不是 $N$ 个。显存回到 $\mathcal{O}(N\max(C,M))$，且与朴素 softmax 实现同量级。

为什么 K 和 V 的梯度是后缀和？（直觉推导）

因为因果掩码。位置 $i$ 的 key/value 会被所有后面的 query 用到——$K_i$ 一旦进入状态 $S_i$，它就留在 $S_i, S_{i+1},\dots,S_N$ 里，影响 $\bar V_i,\bar V_{i+1},\dots,\bar V_N$。所以损失对 $K_i$ 的梯度要把 $j\ge i$ 的所有下游贡献加起来。

形式上，$\bar V_j = \phi(Q_j)^\top S_j$ 且 $S_j = \sum_{m\le j}\phi(K_m)V_m^\top$，所以 $\phi(K_i)$ 出现在所有 $j\ge i$ 的 $\bar V_j$ 里：

$$\frac{\partial \mathcal{L}}{\partial \phi(K_i)} = \sum_{j\ge i}\frac{\partial \mathcal{L}}{\partial \bar V_j}\cdot\frac{\partial \bar V_j}{\partial \phi(K_i)}$$

而 $\bar V_j = \phi(Q_j)^\top\phi(K_i)V_i^\top + (\text{与 }K_i\text{ 无关})$，对 $\phi(K_i)$ 求导得 $\phi(Q_j)\otimes V_i$，代入即得式 (14)。反过来，$Q_i$ 只影响 $\bar V_i$ 一个位置，但它要读取 $S_i$（前 $i$ 项之和），所以是前缀和。

对称性很美：query 向后看历史（前缀），key/value 向前看未来的读取者（后缀）。

6.2 论文的伪代码（Algorithm 1）

function forward(φ(Q), φ(K), V):
    V̄ ← 0,  S ← 0
    for i = 1 … N:
        S    ← S + φ(K_i) V_iᵀ          # 式(10) 前缀和
        V̄_i  ← φ(Q_i) S
    return V̄

function backward(φ(Q), φ(K), V, G):    # G = ∂L/∂V̄
    # ---- 正向扫：Q 的梯度（前缀和）----
    S ← 0
    for i = 1 … N:
        S            ← S + φ(K_i) V_iᵀ
        ∇_{φ(Q_i)}L  ← G_i Sᵀ           # 式(13)

    # ---- 反向扫：K, V 的梯度（后缀和）----
    S ← 0
    for i = N … 1:
        S            ← S + φ(Q_i) G_iᵀ
        ∇_{V_i}L     ← Sᵀ φ(K_i)        # 式(15)
        ∇_{φ(K_i)}L  ← S V_i            # 式(14)
    return ∇_{φ(Q)}L, ∇_{φ(K)}L, ∇_V L

论文说这部分是用约 200 行 CUDA 实现的。分母（归一化项）和除法本身交给 autograd 处理，只有分子这部分需要手写。

这是一个反复出现的模式。 "为了省显存而手写反向、把中间状态重算而不是存下来"——这正是 FlashAttention 的核心思想（2022），也是后来 FlashLinearAttention（Yang et al., ICML 2024）的出发点。区别在于 2020 年这版是纯串行的 for 循环，没有用上 tensor core，实际 wall-clock 并不理想。见第 10.5 和第 11 节。

7训练并行 / 推理常数：两全其美

论文 3.3.2 节的标题是 "Training and Inference"，核心论点用他们自己的话说是 "combines the best of both worlds"：

训练（teacher forcing）推理（自回归）
RNN / LSTM ✗ 必须串行 $N$ 步，状态转移含非线性，无法并行 ✓ 每步 $\mathcal{O}(1)$
softmax Transformer ✓ 全部位置并行，一次大矩阵乘 ✗ 第 $i$ 步 $\mathcal{O}(i)$，KV cache 线性增长
线性 Transformer ✓ 可并行（用式 6 的矩阵形式，或第 11 节的 chunkwise） ✓ 每步 $\mathcal{O}(1)$，状态是固定大小矩阵

为什么线性注意力能兼得？因为它的状态转移是线性且无门控的：$s_i = s_{i-1} + \phi(k_i)v_i^\top$。线性递推的解可以写成闭式的求和 $s_i=\sum_{j\le i}(\cdot)$，因此可以用并行前缀扫描（或直接的矩阵乘）一次算出所有位置；而 LSTM 的 $h_t=\tanh(Wh_{t-1}+\ldots)$ 因为有非线性，无法展开成求和，只能一步步来。

这就是"线性 RNN"这个词的真正含义——不是"复杂度线性"，而是"状态转移是线性的"。这两件事碰巧同时成立，但因果关系是后者推出前者。

代价也在这里。 Transformer 之所以强，一部分原因就是它的"状态"是无损的（全部 KV），而 LSTM 之所以能做状态追踪，一部分原因就是它的非线性递推。线性 RNN 两边各舍弃了一点：状态有损，且转移是线性的。第 13 节会看到，这直接导致它落在 $\mathsf{TC}^0$ 复杂度类内，无法做一般的状态追踪。

8论文实验结果

9为什么它"是" RNN：概念澄清

9.1 与经典 RNN 的三点关键差异

LSTM / GRU线性注意力 RNN
状态形状 向量 $h_t\in\mathbb{R}^{d}$ 矩阵 $S_t\in\mathbb{R}^{D\times M}$ —— 参数量不变的情况下状态容量涨了 $D$ 倍
状态转移 非线性 + 门控：$h_t=\sigma(\cdot)\odot\tanh(\cdot)$ 线性、无门控：$S_t=S_{t-1}+k_tv_t^\top$ —— 因此可并行展开
写入 / 读取 整个状态被整体改写 外积写入、内积读取——是一个键值联想记忆

9.2 状态就是"快权重"

这是理解整条研究线最重要的一个视角转换。看这两个式子：

$$\text{写入：}\; S_t = S_{t-1} + \phi(k_t)v_t^{\!\top} \qquad\qquad \text{读取：}\; \bar V_t = \phi(q_t)^{\!\top}S_t$$

读取操作 $\phi(q_t)^\top S_t$ 在形式上就是一个线性层：输入 $\phi(q_t)$，权重矩阵 $S_t$。区别只在于这个"权重"不是训练得到的，而是在前向传播中由数据即时生成的。

Schlag, Irie & Schmidhuber（ICML 2021, Linear Transformers Are Secretly Fast Weight Programmers）严格建立了这个等价：线性注意力 就是 Schmidhuber 1992 年提出的 Fast Weight Programmer。一个"慢网络"（$W_K,W_V$）生成一串"编程指令"（外积），写入一个"快权重矩阵"（$S_t$），另一路查询（$W_Q$）读取它。

今天这个视角叫 test-time regression / associative memory：把 $S_t$ 看成一个在推理时被在线训练的线性回归器，不同的状态更新规则对应不同的在线学习目标。这个统一视角是 2024 年之后所有工作的共同语言。

用这个视角看，普通线性注意力对应的在线目标是 Hebbian 规则（直接相加），优化 $-\langle S_tk_t, v_t\rangle$；而 DeltaNet 对应的是回归目标 $\|S_tk_t-v_t\|^2$ 走一步梯度下降。这个差别就是第 12 节整条演进线的主轴。

9.3 那 softmax Transformer 呢？

论文特意留了一句话：这个 RNN 表述"does not impose any constraint on the feature function and it can be used for representing any transformer model, in theory even the ones using softmax attention"。

这句话在数学上成立但实践上无意义——softmax 对应的 $\phi$ 无穷维，$S_t$ 是无穷维矩阵，等价于"把所有 KV 都存下来"。这条思路后来被两篇论文明确化：

  • Transformers are Multi-State RNNs（Oren et al., EMNLP 2024）：decoder-only Transformer 精确等价于一个无界多状态 RNN——"隐状态"就是 KV 对的集合，每步增加一个元素。把状态数固定住 = KV cache 压缩，就变成有界 MSRNN。他们的 TOVA 策略（丢掉注意力分数最低的 token）无需训练，在 4 个长程任务上 2/4 用 1/8–1/4 的 cache 就能持平满 cache。
  • Attention as an RNN（Feng et al., 2024）：注意力的分子分母都是 $\sum$，所以是一个 many-to-one RNN；用 并行前缀扫描（Blelloch）配合数值稳定的结合算子 $(m,u,w)=(\max s_i,\sum e^{s_i-m},\sum e^{s_i-m}v_i)$（就是 online softmax 的状态），可以并行算出所有前缀的输出，得到 Aaren 模块。

10局限：忘不掉、记不下、找不回

这一节是全文最重要的部分。理解这五个缺陷，就理解了 2021–2026 年这条研究线上每一篇论文在干什么。

10.1 忘不掉：加法写入，没有遗忘

$S_t = S_{t-1} + \phi(k_t)v_t^\top$ 是纯累加。第 1 个 token 的贡献和第 100000 个 token 的贡献权重完全相同。后果：

  • 注意力稀释：随着序列变长，有效注意力分布越来越平，模型无法聚焦
  • 上下文切换失败：文档换了话题，旧内容仍然完整地留在状态里干扰
  • GLA 论文引用 Buckman & Gelada (2024) 的假设：这是线性注意力在长上下文任务上不稳定的部分原因

修复方向：加衰减/门控。RFA (2021) 的标量门 → RetNet (2023) 的固定 $\gamma$ → GLA/Mamba-2 (2024) 的数据相关门控。

10.2 记不下：状态容量是硬上限

$S_t\in\mathbb{R}^{D\times M}$ 大小固定，与 $N$ 无关。Schlag et al. (2021) 给出了经典的容量论证：外积写入本质是把 $N$ 个键值关联叠加在一个矩阵里，读取靠的是不同 key 之间近似正交。当关联数超过 key 维度 $D$ 时，key 不可能继续保持近似正交，检索必然退化。

修复方向：① 扩大状态（Based 用 2 阶泰勒把 $C$ 撑大、Mamba-3 的 MIMO）；② 更聪明地写（delta 规则：覆盖而不是叠加）；③ 认输，混合架构里塞几层全注意力。

10.3 找不回：recall 是硬伤

这是被最多论文独立验证的经验事实：

  • Zoology（Arora et al., ICLR 2024）：预训练 17 个模型，发现高效模型在 Pile 上落后注意力最多 2.1 ppl，而差距几乎全部集中在"联想回忆"类 token 上。提出 MQAR 合成任务作为诊断标准。理论上：注意力解 MQAR 所需模型维度与序列长度无关，而循环模型在 $d\le\sqrt{N}$ 时需要 $\Omega(N)$ 比特。
  • Repeat After Me（Jelassi et al., ICML 2024）：证明两层 Transformer 可复制指数长的串，而任何固定状态模型受 $m$ 比特信息论上界约束。实测预训练 Transformer 在复制/检索上碾压预训练 Mamba。
  • MiniMax-01（2025）的自家消融是最有说服力的工业证据：纯线性模型在大多数下游任务上追平 softmax，但在 NIAH（大海捞针）上 40.9 vs 混合的 98.0，直接崩掉。他们的结论原话是纯线性注意力 "not suitable for LLMs ... due to their inherent inability to perform retrieval"。
一个漂亮的旁证（Just Read Twice, Arora et al. 2024）：recall 的难度可以归约到通信复杂度里的集合不相交问题——流式模型必须缓存先出现的那个集合。所以 [问题, 文档] 的顺序只需记一个事实，而 [文档, 问题] 的顺序需要记全部事实。他们的解法朴素得可爱：把上下文在 prompt 里重复一遍，16 个现成循环模型 × 6 个 ICL 任务平均涨 +11.0 分。这说明 recall 差有一部分不是容量问题，而是"不知道该存什么"的问题。

10.4 归一化项不稳定

分母 $\phi(q_t)^\top z_t$ 会随 $t$ 单调增长（全正），同时可能在某些 $q$ 上接近 0。Schlag et al. 发现 DeltaNet 只有把归一化删掉才能训起来；反过来把归一化从原始线性 Transformer 里删掉，perplexity 会飙到 1600 以上。

今天的标准做法：删掉分母，改用 GroupNorm / RMSNorm 作用在输出上；$q,k$ 做 L2 归一化（Gated DeltaNet）；或者像 mLSTM 那样用 $\max(|n_t^\top q_t|, 1)$ 稳定化。

10.5 实测速度：FLOPs 少 ≠ 跑得快

这是 2020 年那版实现最被低估的问题。递推形式 FLOPs 最少，但：

  • 逐步更新 $S_t$ 全是外积和矩阵-向量乘，不是矩阵-矩阵乘 → 用不上 tensor core
  • 用并行扫描算法虽然能并行，但需要物化每一步的 2D 隐状态，HBM I/O 开销巨大，反而更慢（GLA 论文点名 Katsch 2023 的 GateLoop 就吃了这个亏）
  • 结果是"理论线性、实测在中等长度（2K–4K）打不过 FlashAttention"

这个问题直到 2024 年才被 FlashLinearAttention 和 Lightning Attention-2 用 chunkwise + I/O-aware 的方式解决——FLA 报告在 1K 长度上就已经比 FlashAttention-2 快。可以说线性注意力在 2020–2023 年沉寂，一半原因是算法，一半原因是 kernel。

13表达能力的理论边界

13.1 线性注意力 = softmax 的一阶泰勒截断

Mongaras & Larson（TMLR 2025）给出了最干净的代数答案。利用 $\exp$ 的泰勒展开和张量积恒等式 $(A\cdot B)^n=(A^{\otimes n})\cdot(B^{\otimes n})$，softmax 注意力的精确递推形式是：

$$O_t = G_t\sum_{n=0}^{\infty}\frac{1}{n!}\big(Q_t^{\otimes n}\big)\cdot H_t^{(n)},\qquad H_t^{(n)} = \sum_{s\le t}\big(K_s^{\otimes n}\big)^{\!\top}V_s$$

截断到 $n=1$：$O_t = Q_t\sum_s K_s^\top V_s = Q_tH_t$——恰好就是 Katharopoulos 的线性注意力。

所以"线性注意力比 softmax 差"不是玄学，而是丢掉了高阶张量积项。他们实测把逐阶泰勒项加回 $1+\mathrm{elu}$、ReLU、cosine 三种线性注意力，性能从"线性注意力水平"平滑插值到"softmax 水平"。这也解释了为什么 Based 用 2 阶泰勒能显著缩小差距、Hedgehog 的诊断（不 spiky 不单调）为什么成立——高阶项正是"尖锐化"的来源。

13.2 复杂度类：递归形式并不带来更强的表达力

The Illusion of State in State-Space Models（Merrill, Petty, Sabharwal, ICML 2024）证明了一个反直觉的结果：尽管有"递归"外观，对数精度下的 S4、Mamba(S6) 和广义线性 SSM 都落在 L-uniform $\mathsf{TC}^0$——和 Transformer同一个复杂度天花板。

  • 技术关键：卷积形式 $h_i=\sum_j\big(\prod_{k=j+1}^{i}\bar A_k\big)\bar B_jx_j$ 需要"迭代乘积"和"矩阵幂"，两者在对数精度下都属于 $\mathsf{TC}^0$
  • 推论：无法求解 $S_5$ 的字问题（置换复合，NC¹-hard），因此原则上无法跟踪棋局、执行 Python、追踪长叙事中的实体状态
  • 但论文第 5 节同时指出：只要引入依赖输入的转移矩阵就能跳出 $\mathsf{TC}^0$——这正是后面两篇论文走的门

13.3 负特征值：一个免费的修复

Unlocking State-Tracking in Linear RNNs Through Negative Eigenvalues（Grazzi et al., ICLR 2025）是这条线上最实用的理论结果：

  • 定理 1：任何有限精度的线性 RNN，若其状态转移矩阵只有正实特征值，则无法在任意长度上求解 PARITY。这覆盖了几乎所有已部署模型——Mamba、RWKV-4/5/6、GLA、mLSTM、原始 DeltaNet，它们的特征值都在 $[0,1]$
  • 定理 2（以 ICLR camera-ready 为准）：需要非三角矩阵才能模 3 计数
  • 定理 3：若转移矩阵是特征值在 $[-1,1]$ 的 $I-\beta k k^\top$ 的乘积，则可学习任意正则语言——正是 DeltaNet 把 $\beta$ 扩到 $(0,2)$ 的情形

修复是免费的：把特征值范围从 $[0,1]$ 放宽到 $[-1,1]$（即 $\beta_t\in(0,2)$），不增加任何训练/推理成本，Mamba 和 DeltaNet 都能解 PARITY，$S_5$ 和模算术上稳定提升，代码和数学 perplexity 变好（TriviaQA 这种纯记忆任务略降，符合预期）。已在 1.3B 预训练上验证稳定。

版本注意：该论文 arXiv v1 的表述是"需要复特征值"，v2 修正了定理 1 和 2，ICLR camera-ready（v3–v5）改为"非三角"。引用时请用 camera-ready 版本。类似地，Based 的头条数字在 arXiv v1 是 6.22 分、ICML 版是 10.36 分。

13.4 三个结论合起来看

为什么线性注意力质量差

它是 softmax 的一阶截断，丢了高阶项 → 注意力权重不够尖锐（13.1 / Hedgehog）

为什么它 recall 差

固定状态的信息论上界，与表达力无关，是容量问题（10.2–10.3）

为什么它状态追踪差

对角/正特征值转移矩阵落在 $\mathsf{TC}^0$ 内；换成非对角、允许负特征值就能跳出（13.2–13.3）

这三个是互相独立的缺陷，需要三种不同的修复。混合架构之所以有效，是因为插入的全注意力层一次性同时补上了三者。

14亲手实现与等价性验证

下面是三种形式的最小 PyTorch 实现，可直接运行，并验证三者数值等价。这是理解这篇论文最快的方式——建议自己敲一遍。

import torch, torch.nn.functional as F

def phi(x):
    """论文式(7)的特征映射：elu(x)+1，保证严格为正"""
    return F.elu(x) + 1.0

# ---------------- 形式 A：并行（二次），最直观 ----------------
def linear_attn_parallel(q, k, v, eps=1e-6):
    """q,k: (B,H,N,D)   v: (B,H,N,M)"""
    q, k = phi(q), phi(k)
    N = q.shape[-2]
    mask = torch.tril(torch.ones(N, N, device=q.device, dtype=torch.bool))
    A   = q @ k.transpose(-1, -2)               # (B,H,N,N) 未归一化注意力
    A   = A.masked_fill(~mask, 0.0)             # 因果掩码
    num = A @ v                                 # (B,H,N,M)
    den = A.sum(-1, keepdim=True)               # (B,H,N,1)
    return num / (den + eps)

# ---------------- 形式 B：递推（RNN），论文式(16)-(20) ----------------
def linear_attn_recurrent(q, k, v, eps=1e-6):
    q, k = phi(q), phi(k)
    B, H, N, D = q.shape
    M = v.shape[-1]
    S = q.new_zeros(B, H, D, M)                 # 矩阵状态  式(10)
    z = q.new_zeros(B, H, D)                    # 归一化状态 式(11)
    out = []
    for i in range(N):
        ki, vi, qi = k[:, :, i], v[:, :, i], q[:, :, i]
        S = S + ki.unsqueeze(-1) * vi.unsqueeze(-2)      # S += φ(k)vᵀ  外积
        z = z + ki
        num = (qi.unsqueeze(-2) @ S).squeeze(-2)         # (B,H,M)
        den = (qi * z).sum(-1, keepdim=True)             # (B,H,1)
        out.append(num / (den + eps))                    # 式(12)
    return torch.stack(out, dim=2)

# ---------------- 形式 C：分块（训练实际用的） ----------------
def linear_attn_chunkwise(q, k, v, C=64, eps=1e-6):
    q, k = phi(q), phi(k)
    B, H, N, D = q.shape
    M = v.shape[-1]
    assert N % C == 0
    q = q.view(B, H, N // C, C, D)
    k = k.view(B, H, N // C, C, D)
    v = v.view(B, H, N // C, C, M)
    S = q.new_zeros(B, H, D, M)
    z = q.new_zeros(B, H, D)
    mask = torch.tril(torch.ones(C, C, device=q.device, dtype=torch.bool))
    outs = []
    for i in range(N // C):
        qi, ki, vi = q[:, :, i], k[:, :, i], v[:, :, i]
        # --- 块间：从压缩历史读取 ---
        num = qi @ S                                     # (B,H,C,M)
        den = qi @ z.unsqueeze(-1)                       # (B,H,C,1)
        # --- 块内：小规模二次注意力（tensor core 友好）---
        A   = (qi @ ki.transpose(-1, -2)).masked_fill(~mask, 0.0)
        num = num + A @ vi
        den = den + A.sum(-1, keepdim=True)
        outs.append(num / (den + eps))
        # --- 状态推进 ---
        S = S + ki.transpose(-1, -2) @ vi
        z = z + ki.sum(-2)
    return torch.cat(outs, dim=2)


if __name__ == "__main__":
    torch.manual_seed(0)
    B, H, N, D, M = 2, 4, 256, 32, 32
    q = torch.randn(B, H, N, D, dtype=torch.float64)
    k = torch.randn(B, H, N, D, dtype=torch.float64)
    v = torch.randn(B, H, N, M, dtype=torch.float64)

    a = linear_attn_parallel(q, k, v)
    b = linear_attn_recurrent(q, k, v)
    c = linear_attn_chunkwise(q, k, v, C=64)

    print("parallel vs recurrent :", (a - b).abs().max().item())
    print("parallel vs chunkwise :", (a - c).abs().max().item())
    # 双精度下两者都应在 1e-12 量级 —— 三种形式在数学上完全等价
建议做的三个实验：
  1. 把 $N$ 从 512 加到 16384，画出三种形式的时间/显存曲线，找到 parallel 的 OOM 点和 chunkwise 的最优 $C$。你会发现 chunkwise 在几乎所有长度上都赢——这就是为什么 2023 年后大家都用它。
  2. 把 phi 换成恒等映射，看 perplexity 怎么变；再换成 lambda x: F.relu(x)+1，观察是否出现"死维度"。
  3. 在递推版里加一行 S = alpha * S + ...（$\alpha\in(0,1)$），你就得到了 RetNet；把 alpha 换成 sigmoid(W @ x)，你就得到了 Mamba-2 / GLA。整条演进线在代码上只差一行。

15常见误解 FAQ

Q1：这篇论文证明了"Transformer 就是 RNN"吗？

不是。它证明的是"线性化的、带因果掩码的 Transformer 是 RNN"。softmax Transformer 只有在"无界状态 RNN"这种平凡意义上才是 RNN（Oren et al. 2024 把这个意义严格化了），而那等价于说"KV cache 是个会长大的状态"，没有效率收益。

Q2：线性注意力是对 softmax 注意力的近似吗？

本文的版本不是。 $\phi=\mathrm{elu}+1$ 定义了一个全新的注意力函数，不试图逼近 softmax。Performer 才是近似（无偏估计 $\exp$ 核）。有趣的是 Mongaras & Larson (2025) 事后表明，线性注意力恰好是 softmax 的一阶泰勒项——所以说它是"一种非常粗糙的近似"也说得通，但这不是原论文的立意。

Q3：既然复杂度 $\mathcal{O}(N)$，为什么 2020–2023 年几乎没人用？

两个原因叠加。质量：无遗忘 + 状态容量有限 → recall 崩，语言建模掉分明显（参见 8.3 的 PER 5.12 vs 8.08）。速度：递推形式没有 matmul，用不上 tensor core；并行扫描要物化 2D 状态，I/O 爆炸。直到 2024 年门控（GLA/Mamba-2）解决前者、chunkwise I/O-aware kernel 解决后者，这条线才真正起飞。

Q4：Mamba 和线性注意力是两回事吗？

不是两回事。 Dao & Gu 的 SSD 定理（ICML 2024）证明：标量转移的 SSM 精确等价于 1-半可分掩码的结构化掩码注意力。Mamba-2 就是"带数据相关标量衰减的线性注意力"，和 RetNet（固定衰减）、GLA（对角衰减）是同一族的不同点。他们论文标题 Transformers are SSMs 就是对本文的致敬。

Q5：那 4000× 加速是真的吗？

数字是真的，但要看清语境：CIFAR-10 自回归逐像素生成的吞吐比（17.85 vs 0.004 images/sec），序列长 3072，且 softmax 基线因显存只能 batch=1 而线性版能开大 batch。这是"长序列自回归解码"这个特定场景的极端值，不是通用加速比。语音识别那栏的加速只有 3×。

Q6：现在还值得读这篇 2020 年的论文吗？

非常值得，因为它是整个领域的词汇表。$S_t$ 的外积更新、三种计算形式、常数内存反向传播、"矩阵值隐状态"这些概念都在这里第一次以现代形式出现。读完这篇再读 GLA / Mamba-2 / Gated DeltaNet，会发现它们全都是在同一个骨架上换 $A_t$ 和换 kernel。
